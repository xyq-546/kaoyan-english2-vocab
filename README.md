# 考研英语（二）词汇辅助 · 线上版

做完题把生词丢进来，它告诉你这词在英语二真题里**考过几年、哪几年**、算不算核心词，
然后按重要程度自动安排复习。

**打开网址就能用。不用开电脑、不用同一个 WiFi。**

---

## 和本机版的区别

| | 线上版（这个） | 本机版（`start.bat`） |
|---|---|---|
| 随时能开 | ✅ 手机流量也行 | ❌ 要电脑开机、同一 WiFi |
| 数据存哪 | **当前浏览器** | 电脑的 `data/records.json` |
| 换设备 | 导出 JSON → 新设备导入 | 自动（服务端是权威副本） |

线上版是纯静态页面，没有服务器，所以数据只能存浏览器里。
**清浏览器数据会丢记录**，建议隔段时间用「我的 → 导出备份 JSON」存一份。
换手机时：老设备导出 → 新设备「导入备份」。

---

## 怎么用

1. **录入**：把生词粘进去，一行一个；也可直接粘整段阅读原文，自动挑词。
   点「先看看认不认得」能先看一眼分档再决定加不加。
2. **复习**：按 `不认识 / 模糊 / 认识` 打分。
   释义区上面是词典释义，高亮框是**「真题里考的是」**——真题实际考的那个义项。
3. **生词本**：筛选、搜索、导出 TSV。
4. **我的**：词汇构成、未来 7 天复习量、考试日期、导出/导入备份。

电脑上按 `1` `2` `3` 打分，`空格` 翻卡。

## 它凭什么判断"核心词"

### 首要依据：英语二真题（2010–2025 共 16 套）

解析自《单词之间：05-25年真题词》，共 2,220 个词条。这份数据关键在三处：

- **英语二专属**（原先只有英语一的统计，只能当代理指标）
- **带真题语境释义** —— 普通词典查不到、但真题实际考的意思
- **带音标**

⚠️ 口径说明：这份资料是"每套卷子挑出该记的词"，**不是全量词频**。
所以"英语二 1 年"只说明某年试卷里有它，**跨多年反复出现才是真高频**
（≥3 年只有 120 个，≥2 年 462 个）。阈值就是照这个定的。

### 辅助依据

大纲 5500 词表（英语一/二共用）、英语一 25 套真题年数、红宝书分区、
npee 的 A 类逻辑抽象词（140 个闭集）、netem 词频排序。

分档规则是**每条证据各自算档、取最高的**：

```
core     英语二真题 ≥3 年，或英语一 ≥20 年
high     英语二真题 ≥2 年，或红宝书必考词，或 A 类抽象词，或英语一 ≥8 年
syllabus 在大纲内，但真题没考过或只考过 1 次
beyond   不在大纲内、英语二真题也没考过
```

共 **7,478 个词条**：核心 756 / 高频 3012 / 大纲 2803 / 超纲 907。

同样"认识一次"，核心词 4 天后复习，高频词 5 天，超纲词 11 天。

### 数据来源与许可

- 英语二真题词来自《单词之间：05-25年真题词》（网络流传物；真题原文著作权属
  教育部教育考试院，本项目只用词汇与词频统计，不含试卷原文）
- 大纲词表、英语一真题年数、A 类词表来自 npee-vocab 项目
- 红宝书数据来自网络流传的结构化版本（原书版权归出版社）
- NETEMVocabulary 为 **CC BY-NC-SA 4.0**

## 目录

```
index.html     页面
app.mjs        主逻辑（录入解析、视图、双模式存储）
schedule.mjs   复习排期算法 + 词库比对 + 词形还原
style.css      样式
vocab.json     词库（7478 词，构建产物，别手改）
404.html       子路径刷新兜底
```

这些是 `tools/build-web.mjs` 从 `public/` 和 `data/vocab.json` 生成的，
**不要直接改这里的文件**，改源码后重新构建。

## 怎么更新

在本机工具目录：

```
node tools/build-vocab.mjs     # 改了词库源数据才需要
node tools/build-web.mjs       # 重新生成 web/
cd web && git add -A && git commit -m "update" && git push
```

推送后 GitHub Pages 约 1 分钟生效。如果打开还是旧内容，
按 `Ctrl+F5` 强刷（GitHub Pages 会缓存静态文件）。

## 已知限制

- 英语二真题数据是"挑出的词"，不是精确词频，**当参考别当权威**
- 真题释义只覆盖考的那一个义项，不代表这个词只有这个意思
- 大纲内外判定不是 100% 准确（词表本身有覆盖差异）
- 词形还原是规则实现，极端情况可能判错
- 复习间隔的档位系数是经验值，在 `schedule.mjs` 的 `TIERS` 里可调
